# Contributing to ReadEase

Thank you for considering a contribution.

1. Open an issue before making a large or breaking change.
2. Explain the user problem your change solves.
3. Keep the project lightweight and dependency-free where practical.
4. Do not add analytics, tracking, or network requests that transmit user text.
5. Test the page on desktop and mobile, and check keyboard navigation.
6. In your pull request, describe what changed and how you tested it.

Small improvements, bug reports, documentation fixes, translations, and accessibility feedback are welcome.
